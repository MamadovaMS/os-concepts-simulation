# Operating Systems Concepts Simulation

Учебные проекты по дисциплине «Операционные системы». Реализация и симуляция ключевых алгоритмов и механизмов ОС на языке Python.

## 📂 Список проектов (Лабораторные работы)

* **Lab 1: Системные вызовы и стек (`lab1.py`)**
  Симуляция работы системных вызовов (`mkdir`, `chdir`, `creat`, `close` и др.) и управления стеком памяти.

* **Lab 2: Планировщик Round Robin (`lab2_scheduler.py`)**
  Симуляция алгоритма планирования потоков (Round Robin). Расчет времени ожидания и времени завершения для каждого потока.

* **Lab 3: Замещение страниц (`lab3_memory.py`)**
  Симуляция алгоритма замещения страниц «Второй шанс» (Second Chance). Подсчет Page Faults (промахов) и Hits (попаданий).

* **Lab 4: Файловая система (`lab4_fs.py`)**
  Симуляция файловой системы с I-нодами. Реализация выделения секторов (прямых и косвенных), создание файлов и директорий, карта диска.

* **Lab 5: Обработка прерываний I/O (`lab5_io.py`)**
  Симуляция обработки запросов ввода-вывода (I/O). Сравнение режимов с блокировкой процесса (interrupts) и без нее (busy wait).

* **Lab 6: Предотвращение взаимоблокировок (`lab6_deadlock.py`)**
  Реализация «Алгоритма банкира» (Banker's Algorithm) для проверки состояний системы на безопасность и предотвращения deadlock.

## 🛠 Стек технологий
* **Язык:** Python
* **Парадигмы:** ООП, событийно-ориентированное моделирование
